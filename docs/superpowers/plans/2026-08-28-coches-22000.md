# Coches por menos de 22.000 € Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Construir una guía web estática, contrastada y responsive que recomiende coches nuevos y usados por menos de 22.000 € para uso urbano con garaje propio.

**Architecture:** HTML/CSS/JavaScript sin dependencias de producción. Los datos y la lógica pura usan un envoltorio UMD para funcionar en navegador y en las pruebas nativas de Node; el DOM consume esa API y renderiza el comparador.

**Tech Stack:** HTML5, CSS moderno, JavaScript ES2022 compatible con navegador, `node:test`, servidor estático de Python.

**Spec:** `docs/superpowers/specs/2026-08-28-coches-22000-design.md`

## Global Constraints

- Mercado español y datos fechados a 28 de agosto de 2026.
- Presupuesto neto máximo de 22.000 €; cualquier desembolso inicial superior debe avisarse.
- Precio al contado, precio financiado, ayuda y deducciones se muestran por separado.
- Sin dependencias de producción, sin API y sin proceso de compilación.
- Accesibilidad WCAG 2.1 AA y layouts verificados a 320, 768, 1024 y 1440 px.
- Cada vehículo incluye una fuente utilizable y un estado de evidencia.
